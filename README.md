## 📂 Featured Projects

### 🧠 SEHAJ: Multi-Agent Mental Health Chatbot
**Tech:** Python, LangGraph, Llama 3.3, Groq, Streamlit

Built a LangGraph-based multi-agent system with six specialised agents for intent routing and context-aware task handling.

- Developed a Guardian safety protocol that achieved 90% interception accuracy in high-risk scenarios, with 0% false positives in benign emotional conversations.
- Reduced token overhead by 54.7% and achieved 0.71-second average latency using Groq.
- Received a CTRS therapeutic validation score of 4.47/5.

### 🔍 Mental Health Text Classification
**Tech:** Python, Transformers, Scikit-learn, Streamlit

Developed an NLP pipeline to classify 51,000+ social media posts across seven mental health categories.

- Evaluated MentalBERT, BioBERT, and PubMedBERT.
- MentalBERT achieved an F1-score of 0.84.
- Deployed the classification pipeline using Streamlit.

### 🛒 Hybrid Product Recommender
**Tech:** Python, Sentence-BERT, SVD, Scikit-learn

Combined SVD-based collaborative filtering with Sentence-BERT embeddings using an Amazon dataset of 73K reviews.

- Evaluated recommendations using Precision@10, Recall@10, and NDCG@10.
- Achieved approximately 4× the Precision@10 of a review-sentiment-only baseline.
- Co-authored project presented at ICADT 2025.
